# AOT 布尔重复列表紧凑存储

## 实现及语义

仅单元素、精确bool、正次重复的新结果使用List<bool>；普通二元乘法与root list.__mul__共享工厂，
各自参数和错误合同保留，root __index__先回调及检查容量再判定当前source。
已有通用列表不重新紧凑化；整数1不会按True压缩。Copy可复制已有布尔背板。
布尔读写、追加、pop/clear/reverse及迭代保留紧凑；异构写和Items访问完整构建规范bool单例列表后发布，
原PyList身份不变，Items暴露后的同一List实例永久保留。复杂协议沿既有物化路径。
数值列表的迭代物化合同不变，布尔探测不物化且浮点守卫返回false。
Count保持object/数值优先并显式内联，可信ReadCheckedF64仍要求同一守卫真边且无回调/写入。

每个PyList增加一个8B引用字段，代价由全26项测量；未改对象GC布局或公开ABI。
分配几何、资源耗尽时刻与临时物化容量沿性能边界，不承诺与CPython逐分配同刻失败。
决定见[ADR-0197](adr/0197-boolean-repeat-list-storage.md)。

## 验证

25项C#专项通过（含既有10项数值列表），覆盖正反/root重复、bool身份、异构写、Items永久别名、
活迭代/耗尽、自扩展、自引用和数值互操作。100000元素构造实测分配在100000–200000字节，
严格排除8B引用数组；写入及完整迭代后仍紧凑。
固定CPython3.12.13/JIT/真实NativeAOT、源码和构建隐藏、中文搬迁与空PATH完整双流一致。
随包NumPy2.3.5转换及operator.setitem布尔/异构双向同步同样通过。
主用例已转正，运算符用户__index__的既有缺口单独保留pending，见semantics §4.18。

最新完整make check退出0；fmt、workspace严格Clippy、Rust、754项cases及编译e2e472通过/286忽略。
25项C#专项之外的完整C#套件随门禁通过；既有xUnit分析器警告保留。
共享工作区生成器活跃性仍为test-only，未纳入本次产品提交。

## 修正与准入

首版matmul稳定回退约18%，精简冗余bool守卫后仍约16.6%；均未准入。
Count数值优先分流和显式内联后，三臂1warm10剩余约3.22%，最终全26项配对为0.95%。
当前接受该局部速度与字段分配代价，以换取筛法的确定提速和内存改善；后续继续保护数值热路。
不从二进制大小或内联属性直接推断机器码归因，未做反汇编证据的向量化/寄存器说法撤回。
前轮报告Alloc曾误读managed_alloc_bytes并默认0，已撤回；原始JSON实际alloc_bytes保留并在本轮严格校验。
