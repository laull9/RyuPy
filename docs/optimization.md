# 前瞻优化计划

本文安排尚未实现的优化，现有控制流简化与基础常量折叠继续保留。原计划以项目阻塞优先；经用户批准的当前执行顺序见下文，独立兼容门仍保留。每项优化先有正确的通用路径，再加入证明或守卫。路线图见 [roadmap.md](roadmap.md)，阶段任务见 [TODO.md](../TODO.md)。

## 测量方法与当前基线

所有优化先测量再启用。`make bench` 覆盖静态数值、动态调用、对象、容器、字符串、算法、异常与项目式切片
共 22 个基准，同时记录墙钟、进程内执行耗时、托管分配、GC、JIT 与峰值内存；`make bench-save` /
`bench-compare` 保存与对比，`make bench-profile` 定位热点（用法见 [tests/README.md](../tests/README.md)）。
M2.12 的基线与各项优化的收益、边界见 [ADR-0014](adr/0014-benchmark-suite-and-dynamic-hot-paths.md)：
几何平均为 CPython 的 0.53x，静态路径 2.8x，动态调用约 1.0x，容器 / 字符串 / 异常 / 项目式代码 0.25–0.5x。
剩下的差距主要来自装箱值上的类型分派，正是下文 Phase 3 收窄、特化与逃逸分析的目标。

## Phase 2 先留下接口

| 对象 | 设计预留 | 验证与退路 |
| --- | --- | --- |
| `PyValue` | 标量直接存储，堆引用与数值槽分离；比较 ADR-0003 两种 GC 合法布局 | 测算术、调用、容器访问与 GC，不把“动态值”统称零分配 |
| 动态调用与运算 | 每个 call site 有固定上限的单态 / 多态缓存，超限转通用分派 | 类型、运算槽与版本都匹配才命中；测试重定义和多态抖动，避免缓存无限增长 |
| 普通对象 | shape / 属性槽位、类版本号、继承关系版本 | 增删属性、替换方法或 property 后失效；保留绑定方法与引用身份 |
| 模块 | 稳定模块身份、全局槽位、绑定版本 | `global` 写入、模块属性重绑定、循环初始化不能命中旧值 |
| 数值 | i64 常见路径，大整数通用路径，范围证明独立记录 | checked 溢出后升级；类型标注不足以证明不溢出 |
| 容器 | 通用 `PyValue` 元素；后续允许内部同质存储策略 | 混入其它类型时转换且保留共享别名、顺序与迭代语义 |

这些接口首先承担正确性约束。PIC、shape 等实现要由基准证明收益，再决定默认启用范围。缓存失效不推迟到元类阶段。

截至 M2.12 的落地情况：PIC（每站点 4 条、轮转替换）、实例属性槽位、property / 类属性 / `super()` 缓存、
模块槽位、i64 快路径（无异常的溢出检测）与小整数 / bool 装箱缓存已实现；类版本当前是全局版本号，
按类细分版本、容器同质存储仍是待做项。

## 当前执行顺序与实证约束

经用户批准将标准库交付与项目兼容门拆分，M3.7已交付，固定入口仍5/20；
按明确JIT方向优先M3.9→M3.10。M3.8桥接保持未完成后排，原16/20目标保留M3.11，
不再用追逐单库新链无限阻塞有证据的原生优化。
首个M3.9实验复用已有严格非逃逸累加候选，探索直接typed CIL状态和整数快路。
当前基线的holder helper在Tier1/FullOpts已被JIT内联，不能仅以CIL少了call宣称收益；
必须比较实际机器码、状态寄存器/对象存储、分配及稳态分布。无收益则不默认启用。
三组直接局部实验已完成配对：分配减少，但吞吐未达到默认门槛，保留 holder 默认。
直接方案仅显式实验开关，详见 [ADR-0033](adr/0033-direct-cil-guarded-accumulator.md)；
模式接线与完整里程碑门禁已通过，实验仍默认关闭。
随后新鲜临时 tuple 的同块非逃逸标量替换已通过净收益与完整门禁，按8元素/32次尝试预算默认启用，
详见 [ADR-0034](adr/0034-fresh-tuple-scalar-replacement.md)；返回、别名、身份观察、EH与暂停保留对象。
有限纯叶调用实验也已停止调参：成功路径获益，但已知整数参数的身份失配仍重复退化，
因此默认保原调用，仅 `--experimental-leaf-inline` 显式启用，见 [ADR-0035](adr/0035-guarded-leaf-call-specialization.md)。
非 SSA 上的有限合流整数区间与原位自动拆箱已通过专项配对和完整代码门禁；不增加运行时猜测。
接受有界默认，整套默认main几何耗时+2.8%的混合结果与未改写对照不利时间均完整保留，见 [ADR-0036](adr/0036-bounded-interval-unboxing.md)。

M3.10 首切短F64算术链已在真实矩阵/N-Body命中：精确double守卫、原顺序CIL运算，
仅最后装盒，未知类型原链回退。唯一配对两核心双tier耗时/分配均改善，接受有限默认；
首bool/int失配的默认tier退化也完整保留，不称普遍收益，见 [ADR-0037](adr/0037-guarded-float-chain-scalarization.md)。
首切聚合正确性门禁已通过；不是一般容器特化或SIMD已经完成。
严格内层浮点累加的跨迭代原生槽已按[ADR-0038](adr/0038-inner-float-loop-materialization.md)完成：
相对短链基线真实矩阵两tier分别改善16.2%/20.3%，分配再少98.1%；多态失败退化与代码增长保留。
第二切聚合门禁通过（423 C#、222基线、197 e2e/29 ignored），不代表整个M3.10完成。

用户追加动态union方向后，ADR-0003/0010重新进入表示评估：GC禁止的是引用/标量重叠，
不是禁止合法16B/24B布局，也不能因当前容器为object就断言union容器仍必须盒装。
独立原型同时比较数值、按值/按引用调用、对象边界与union数组；复制别名后惰性物化
的身份问题必须显式处理。阶段2为便于闭环选择object，不是永久性能架构结论。
当前生产仍保持已验证路径，不凭scratch吞吐直接切换全ABI。

## Phase 3 按热点推进

| 优化 | 证明或守卫 | 不能越过的边界 |
| --- | --- | --- |
| 流敏感收窄与拆箱 | `isinstance` 结果结合真实类型、值域和合并点数据流 | bool 与 int 子类型、自定义运算符、分支合流均须处理；不把 isinstance 直接等同 exact-type |
| 函数特化与有限单态化 | 基于调用类型与代码版本预生成有限变体，入口守卫失败走原实现 | 类型标注不新增运行时拒绝；限制代码体积；默认不要求运行时生成 IL |
| 临时元组 / 对象标量替换 | 不逃逸、身份不可观察、字段别名与副作用已证明 | 返回、捕获、容器存储、`id` / `is` 和跨暂停点可能要求物化为对象 |
| 迭代器融合 | 已知迭代器实现、消费顺序与异常位置 | 用户迭代器副作用、生成器 close / throw 和资源清理阻止不安全融合 |
| 循环不变量外提与边界合并 | 别名、可变长度、异常与调用副作用分析 | 回调、容器修改、模块重绑定、yield 后重新验证 |

保持非 SSA MIR；先评估迭代数据流分析是否足够，再决定临时 SSA 视图，按 ADR-0002 补决策。codegen 只消费已选定的 MIR 操作和运行时引用，不自行猜 Python 对象行为。

## 非纯 Python 模块可引入之后的数据面优化

Phase 4 先验收 NumPy 等模块的导入与基本调用。本节优化不属于 Phase 4 的完成门槛，按项目热点另排任务。

以批量调用减少 FFI 次数；把对象转换、复制和纯计算分别计时。仅在 dtype、stride、对齐、可写性与生命周期成立时生成专门化数组循环。连续数组可以研究 SIMD；非连续视图保留一般路径。

浮点重排、fast-math 与固定宽度整数会改变可观察结果，不能作为默认优化。若收益足够，再新增显式性能扩展、ADR 和差分用例。DLPack 所有权与设备同步单独验收。

## Phase 5 部署与长期运行

测量 CLI 启动、编译、模块初始化、JIT 冷启动、稳态吞吐、AOT 构建时间、产物体积、分配量和峰值内存。报告保留输入、机器、系统、工具链、预热、重复次数和离散程度，不混合冷启动与稳态结果。

形状表、特化变体、导入缓存和桥接包装都要说明增长边界。PIC / 特化限制容量，shape 考虑弱引用或回收；模块缓存保持 Python 的导入身份语义，不能为了内存上限随意逐出模块。对重复创建对象、重新绑定和桥接回调做长期运行测试。

每项优化需有未启用路径的对照、可复现性能记录和覆盖失败守卫的语义回归。未证明收益的复杂优化保持待做；不开倒车扩大项目的语义偏差。

[ADR-0039](adr/0039-adaptive-numeric-list-island.md) 的自适应数值列表岛已接受有界默认：
普通引用槽不变，仅严格新鲜追加与精确读双端命中改内部背板；共享身份在观察/复制前物化。
三臂隔离runtime/编译体成本；唯一修正后矩阵双tier改善30.5%/41.3%、分配净少8.10%。
普通wrapper+8B、bool失败守卫变慢与代码增长完整保留，不是通用union或全部list提速。
完整门禁433 C#、224基线、198 e2e/30 ignored已通过。

[ADR-0040](adr/0040-guarded-two-lane-float-slp.md)的有限两lane同形SLP已实现真实向量CIL及packed机器码，
ISA关闭回退、2000组位模式与不同结果盒身份均通过；同守卫scalar控制与packed分配相同，
packed无净收益，故仅显式实验/诊断开关，默认均关闭。原SIMD要求不是以纯研究代替。
[ADR-0041](adr/0041-proven-list-read-bounds.md)另补独立must证明下的可信读取，
只消除第二次显式逻辑范围判断，保CLR List/数组安全检查；实际机器码已确认该层比较消失，分配不变、代码+130B；最终聚合门禁已通过（434 C#、225基线、199 e2e/30 ignored），整26共104冷进程均通过；但25项冷main几何耗时退化9.54%/8.15%，
不宣称整个项目净加速，热专项与冷覆盖详见[最终验收报告](notes/2026-11-01-m3.10-validation.md)。
