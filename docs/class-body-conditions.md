# 普通类体条件语句

M3.7 的此竖切支持普通类体中的 `if / elif / else`，包括嵌套条件。它是类定义位置执行的普通控制流，不是平台名称特判，也不在 HIR 以常量折叠跳过未选分支的语法检查。

## 执行与名称查找

- 条件按源码顺序求值并判真；只执行选中分支，随后继续类体。属性赋值、方法定义、表达式副作用保留原有顺序。
- 同名方法出现在不同分支时，各自按源码范围登记独立函数，只把实际定义的方法写入类字典。装饰器表达式先于默认值、即时标注求值，再逆序应用装饰器。
- 类名字分析分别记录“可能已绑定”和“必定已绑定”。两分支从同一个入口状态降级；合流分别取并集、交集。没有 `else` 时还包含入口状态。
- 必定绑定名字沿用直接 `ClassNamespaceGet`。可能绑定名字先调用纯 own 字典检查 `ClassNamespaceContains`；存在时读取类字典，不存在时才求模块/内建回退表达式。不能提前求值回退，也不能沿基类查找裸名字或在类体读取时绑定描述符。`None` 是存在的值，不代表缺失。
- 方法默认值、即时标注与装饰器使用定义位置的类命名空间；方法函数体不捕获该命名空间，仍按函数规则读取模块名字。
- 若可选类名字遮蔽了尚未实现的内建，实际类字典已有值可以使用；真正执行未实现内建回退时明确 `NotImplementedError`，不在未执行路径提前发诊断或伪装为用户未知名。
- 既有“模块同名槽未绑定时完整 builtin fallback”仍是独立未实现边界，见 [模块绑定状态](module-binding-state.md)。本切不宣称完整动态 `LOAD_NAME`、元类 `__prepare__` 或任意映射命名空间支持。

## 注解与后置 dataclass

语法上类作用域任意分支有 `AnnAssign` 时，在第一条类体语句前初始化 `__annotations__`，即使声明只位于 `if False` 中。扫描不进入方法体或独立嵌套类。只有执行到的简单名字声明才写入字典；无初值标注不把被标注名字当作已绑定值。括号名字 `(name): annotation` 在非 future 模式只求标注表达式、不登记字段；若有初值，先赋值再求标注。future 模式的非简单标注不求值，空字典的语法级初始化仍保留。

含条件语句的普通类不再登记旧的静态 `DeclareDataclass` 字段后备表。后置 `dataclass(C)` 使用类实际 `__annotations__` 的键：未执行字段不被静态并入；删除该字典后应用得到空字段。没有新增拒绝标记，也没有在普通实例访问路径检查 dataclass 条件状态。

显式 `@dataclass`、已识别的原生 `Enum` / `TypedDict` 类体条件本切仍发 `E0100`，不将分支字段静态合并为必有成员。此范围不改变既有后置 dataclass 自身的继承等限制。

## 边界与成本

- 类体循环、`try / with`、嵌套类、链式及解包类属性目标等仍沿既有诊断边界；未因增加 `if` 全面开放普通语句。
- HIR 保存分支和名字状态，MIR 构建普通基本块。CIL 后端只消费分支及静态运行时 ABI，不解释类体、不猜测 Python 名字。
- 名字集合复制和合流发生在编译阶段。运行时仅可选绑定读取增加一个 own 字典检查与分支，命中时再做一次既有字典读取；这是冷类定义路径接受的两次查找，没有方法调用/实例字段访问解释器或 PIC 热路径检查。
- 不把模块数值槽统一改成 Dynamic；继续遵守原有类型模式及模块绑定检查规则。未做支配分析消除可选字典查询，也没有未经测量的加速声明。

## 验收

- `m3_7_class_if_order.py`：条件/嵌套分支源序、同名方法选择、装饰器/默认值/标注顺序。
- `m3_7_class_if_lookup.py`：惰性模块/内建回退、None、基类不参与裸名查找、方法体作用域、空注解字典、后置 dataclass 与删除注解字典。
- `m3_7_class_if_nonsimple_annotations.py`：条件/直线类体的括号名字标注副作用、赋值顺序与后置 dataclass 不产生伪字段。
- HIR `class_if_tests`：方法源码范围不重复、注解预初始化、特殊类条件明确拒绝。
- driver `class_if`：HIR/MIR/CIL 快照；可选 `locals` 名字命中成功、缺失才明确拒绝的真实进程回归。
- MIR 验证器检查 `ClassNamespaceContains(object, str) -> bool` 参数、返回目标与不得遗留返回值；C# `PyClassNamespaceTests` 锁定 own 字典、None、继承隔离和描述符不执行。
