# M3.7 random 有限原生实现与序列验收

## 算法和来源

运行时以C#独立实现MT19937的624个32位状态字、397偏移、temper参数和2002数组播种算法；
不是System.Random适配器，也不在运行时调用CPython。没有粘贴CPython或MT参考C源码。

算法来源：M. Matsumoto、T. Nishimura，1998年MT19937论文；数组播种/53位实数设计见
作者2002说明页 https://www.math.sci.hiroshima-u.ac.jp/m-mat/MT/MT2002/emt19937ar.html 。
Python API语义见 https://docs.python.org/3.12/library/random.html 。固定CPython3.12.13仅
用于黑盒行为对照和生成测试事实；本轮不移植其random.py/C实现或上游测试源码。

## 首批范围

- 稳定Random原生类型、独立实例与共享默认实例的模块函数。
- seed：None用操作系统熵；int使用绝对值全部位；version=2的str先严格UTF-8编码，
  bytes/bytearray使用原字节。原字节拼接SHA-512摘要后按大端无符号整数播种。
- random：顺序抽两字，分别取高27/26位组成53位浮点数。
- getrandbits：支持0与跨32位，0不消费状态；最后不足32位的字取高位，字序低字在前。
- randrange/randint：整数索引协议、任意精度边界、正负step、拒绝采样。2的幂边界仍取
  n.bit_length()位并拒绝越界结果，不能以减少抽样为由破坏后续消费序列。
- choice/shuffle：使用真实len/下标/赋值协议，不先复制迭代器；shuffle保留先读两值再写
  两位置的顺序，并修改原对象。

MT输出不用于密码学安全用途。未实现version=1、浮点种子、getstate/setstate/gauss，明确
NotImplementedError；未列出的分布、SystemRandom及Random子类扩展不在此首批范围。
getrandbits和范围位宽沿用PyInt.MaxBitShift的一百万位资源边界，超界明确拒绝，不截断值。
version参数仅承诺内置标量2；自定义version对象及其相等运算副作用不在兼容范围。
未承诺多线程调用间的固定交错序列。

## 可复现证据

`tests/generate_random_baseline.py` 强制固定CPython3.12.13，输出
`tests/data/random_cpython_3_12_13.json`：含0/正负/超64位整数种子、UTF-8、bytes、bytearray，
跨字位数与浮点交错消费，以及1000字换轮摘要。C#focused测试和m3_7_random.py分别验证
核心向量与真实编译路径，另外覆盖错误不消费状态、模块共享/实例隔离、自定义索引和序列副作用。
Release运行时focused 7/7通过；固定CPython3.12.13真实编译差分 m3_7_random 与原
m3_7_helpers 均通过并已转正，随后仍须里程碑统一全门禁。最初测试直接书写超过u64的十进制
常量触发现有前端E0100，改用等值 `(1 << 80) + 7` 构造种子；这不改变随机预期，也不宣称
本轮实现超范围十进制字面量。固定项目通过率另行计算，不能从模块或两用例通过外推。
