# M2.11 动态热路径：去分配而不改表示

- 日期：2026-10-31
- 关联里程碑：M2.11
- 关联 ADR：[ADR-0013](../adr/0013-dynamic-hot-path-allocations.md)

## 做了什么

目标很明确：动态基准比 CPython 慢约 5 倍，而 profile 显示大部分时间不在 `switch`，而在分配与
多余调用帧。逐项处理：

1. **调用点复用参数数组**：MIR 增加 `DynCallValue` / `DynCallMethod`（纯位置、≤3 个实参），
   运行时 `PyPic.CallValueN` / `CallMethodN` 把 `self` 与实参直接写进调用点自己的数组。
2. **thunk 快路径**：参数个数正确且无关键字时，生成的 thunk 直接 `args[i]` 拆箱调用静态方法；
   不匹配才进 `PyBinder.Bind`。Bind 自己也增加「纯位置、实参占满」的无分配快路径。
3. **字面量池**：codegen 收集 `Box` 的数值常量，模块初始化时装箱一次并写静态字段。
4. **实例属性槽位**：`PyClass` 维护属性名→槽位表，`PyInstance` 用 `object?[]` 存放；
   删除写未赋值哨兵。类版本在新增槽位时递增。
5. **属性 PIC**：`DynGetAttr` / `SetAttr` 带站点编号，命中时直接读写槽位；类版本、槽位未赋值时
   回退 `PyObject` 通用路径。
6. **方法 PIC**：缓存绑定方法、类版本与「方法名对应的实例槽位」；只有该槽位被赋值才可能遮蔽。
   函数不调用 `super()` 时跳过方法上下文保存/恢复。
7. **数值与展开快路径**：`long + long` 直接 `PyInt.AddI64`；`FlattenArgs` 在没有 `*` / `**` 时
   复用原数组；空关键字数组共享。

## 结果

`tests/run_benchmarks.py`（macOS arm64、.NET 10.0.403、CPython 3.13.13、Release）：

| 基准 | CPython (ms) | M2.9 | M2.11 |
| --- | ---: | ---: | ---: |
| dynamic（300 万加法 + 200 万方法调用） | 162 | 792 | 196 |
| dynamic（PIC 关闭） | 162 | 819 | 386 |
| add_only（300 万次动态加法调用） | 102 | 463 | 98 |
| call_only（300 万次动态调用） | 80 | 347 | 67 |
| method_empty（200 万次空方法） | 50 | 153 | 68 |
| method_add（200 万次 `self.v += 1`） | 67 | 425 | 132 |
| containers（20 万 append + 10 万字典 + 5 万拼接） | 33 | — | 176 |
| fib | 288 | 154 | 155 |
| mandelbrot | 1237 | 274 | 266 |

动态基准整体快约 4 倍；纯动态调用已经快于 CPython。固定 CPython 3.12.13 的 `make bench`
中 dynamic 为 196 ms（CPython 192 ms，0.98x），PIC 关闭为 384 ms。静态路径不受影响。

## 踩到的坑

- **方法缓存每次写属性都失效**：最初把「实例属性版本」作为方法缓存键，而 `self.v += 1` 每次
  都改版本，导致缓存命中率恒为 0，反而比不做缓存更慢。改成「方法名对应的实例槽位是否赋值」，
  其它属性的写入不再影响方法查找。
- **通用调用路径忘了传站点编号**：小参数调用改用 `PyPic.*N` 后，大于 3 个参数/有关键字的调用
  仍然走 `Rvalue::Call`。codegen 已经压入 site，但方法引用换成了不带 site 的 `PyOps` 版本，
  结果多出一个栈值，CLR 报 `invalid program`；用 ilverify 定位到 `ReturnEmpty` 后修正。
- **字面量池的初始化顺序**：池字段必须在任何模块代码之前写好；`__init_literals` 被插入
  `__init_functions` 的最前面。
- **槽位与 property 的优先级**：属性槽位不能绕过数据描述符。`HasProperties` 为真时先走
  property；属性 PIC 对这类类直接回退。
- **thunk 快路径不能改变错误语义**：参数个数不对或有关键字时必须回到 `PyBinder.Bind`，
  否则重复绑定、缺参等 `TypeError` 会丢失。

## 还没想明白的

- 字符串拼接仍是最大差距：`.NET string` 不可变，CPython 在引用计数为 1 时可以原地扩容。
  要追上需要改变动态字符串表示或做循环级 StringWriter 改写，影响面远大于当前优化。
- 字典键的装箱与哈希仍是容器路径的主要成本；如果后续项目热点落在字典，再单独评估键表示。
- 实例槽位按类只增不减。大量动态属性名的长时间运行需要容量上限或回退字典；当前先记录边界。
