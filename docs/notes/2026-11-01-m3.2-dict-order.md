# M3.2：字典字面量求值与hash时序

普通及暂停字典字面量现按固定CPython基线分批插入，修复旧路径过早调用用户hash的问题。
≤15对先求全体key/value，16–17对逐对求值插入；不是为了优化而改变可观察副作用。
先pending失败，再实际差分unexpected-pass后转正；覆盖边界、暂停、重复键和异常短路。
超过17项仅纯标量字面量键安全子集直接插入；动态键分块缓存hash合并明确诊断并保留pending。
ADR-0023明确分界来自固定CPython3.12编译策略，未来升级需重验；`**`字典合并仍不支持。

验证：`make runtime`与完整`make check`全绿，131项C#、70编译差分通过/20忽略，
86项CPython基线/框架；`make projects`仍native 0/20，未据语法覆盖外推项目覆盖。
