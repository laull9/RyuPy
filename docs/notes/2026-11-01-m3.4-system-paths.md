# M3.4：系统、路径与文件

## 目标与实现

整里程碑交付声明范围的 sys/io/open/os/os.path/pathlib，不以模块导入冒充完整兼容。
逐 API 表见 ../stdlib-system.md，设计与性能边界见 ADR-0028。
原生对象与有限类型注册统一动态协议；文件系统适配留运行时，CIL 只引用有限 ABI。
保留静态 print 类型化路径，同时冻结目标流并支持动态 file/flush。

## 修复的边界

- 实际 argv[0] 与 traceback 显示名分离；环境直接 putenv 不回写 environ。
- print 的 flush 真值转换在写入前，目标 None 提前返回；input 不多删 CR。
- Path.absolute 不归一化 ..；路径查询不把权限错误一律吞成不存在。
- nullable 宿主回调统一 None，避免把 close/flush 返回值存成未绑定模块槽。
- SystemExit 的对象格式化延迟到报告，坏 __str__ 与大整数退出不泄漏 CLR 异常。
- 每个当前输出流独立刷新；坏 stdout 不妨碍 stderr 文件落盘，失败退出 120，不 close。
- readlines(None)、关闭后参数错误优先级与初始化失败释放句柄均有回归。

## 明确限制

Windows 词法拒绝有注入测试，不等于 Windows 实机通过；文件权限映射的注入测试不冒充非root实机。
完整 io.UnsupportedOperation 层级、文件描述符、编码错误策略、复杂 glob 及解释器内部接口仍未支持。
文本逐码点分配、目录首次 next 快照、受控模块视图与退出单次刷新策略均公开登记；未测速度不承诺加速。
