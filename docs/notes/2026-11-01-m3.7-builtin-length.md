# M3.7 内建对象的一等绑定__len__

texttable的自定义len对非字符串调用iterable.__len__，暴露出内建len已支持而方法属性缺失
的通用缺口。本轮统一支持精确list、tuple、dict、set、frozenset、dict视图、bytes、
bytearray、str九类；没有修改第三方源码或只为list特判返回固定值。

PyPreparedMethods存在性/绑定入口与PyCollectionOps直接方法调用共同使用PreparedLength；
严格零参数、拒所有关键字，取方法时不计算长度，调用时才读接收者当前状态。
字典视图随底层字典变化、已绑定list方法随append变化；字符串仍按Python码点计数。
NativeObject、用户实例、类等优先保持原属性协议，不加入MayHaveMethods热路径回调。

复用PyBuiltinMethod表示，仅该__len__槽标记method-wrapper：type名、repr类别、
__self__/__name__/__qualname__/__objclass__及缺失__module__与固定基线一致。
同一对象同一方法相等且哈希相同，别的等值容器不视为同一方法；不调用容器用户eq/hash。
未实现list.__len__等未绑定slot descriptor、完整types模块或list子类模型，不宣称这些兼容。
