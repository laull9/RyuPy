# M3.7 typing.Literal 有限值元数据

为真实 termcolor 导入 typing.Literal 的阻断实现运行时元数据，不是空导出或忽略订阅。
本轮支持 None、bool、int（含大整数）、str；字符串是值而非前向类型引用。
嵌套 Literal 展平并按首次出现顺序保留参数；去重与等价比较区分 bool 和 int。
不同顺序但同一类型敏感值集合相等且哈希相同，repr/get_args 保留各自参数顺序。
get_origin(裸 Literal) 为 None，参数化对象的 origin 是稳定 Literal 形式；
空订阅 Literal[()] 保留空参数与对应 repr。不可实例化或用于 isinstance。

复用 typing 原有最多128项有界缓存，仅 Literal 的键增加实际类型标签；
值分类不读取用户 __class__、不调用用户 __eq__/__hash__。Enum、float、自定义实例等
未支持值明确抛 NotImplementedError，不把它们当作标量或伪装完整 Literal 兼容。
不改变现有 Union/普通泛型的相等与哈希逻辑，也不增加逐实例反射。

固定 CPython 3.12.13 黑盒已验证上述 repr、参数展平、类型敏感去重、顺序无关相等/哈希与
调用/isinstance 的 TypeError。真实编译差分位于 tests/e2e/phase3/m3_7_typing_literal.py；
Release typing 焦点5/5通过；该固定解释器真实差分已通过并转正。使用既有已验证项目驱动器
定向复测 termcolor 得到 native、输出一致；这是单项目1/1的验证，不代表固定全项目分母或
里程碑统一门禁已完成。
