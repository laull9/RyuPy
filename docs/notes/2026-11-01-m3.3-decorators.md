# M3.3：定义位置装饰器、公开绑定与动态数据类

## 完成范围

保留原始四项验收：函数/类装饰表达式顺序与逆序应用、callable/闭包/方法绑定、
声明范围函数元数据，以及dataclass/property集成。所有小切保持未提交，最终按整M3.3提交。
混合dataclass用PyClass/PyInstance，纯dataclass保留静态字段优化；取舍见ADR-0027。

## 发现与修复

- 公开槽与原始函数/类内部ID分离，只有整链成功才绑定，模块导出也优先公开槽。
- 模块未初始化变量原来置None，导致装饰失败后名字读到None；改未绑定null并保留LoadName检查。
- 类体默认值/装饰表达式读当前原始类namespace，lambda/method body不把类当闭包。
- classmethod从实例访问原误传实例；统一绑定实际访问类，并保留定义类super上下文。
- dataclass激活在准确装饰位置，替代类字段取自身声明，frozen取本次装饰标记。
- 初始化保property setter；异类eq返回NotImplemented供另一侧反射。
- 专用dataclass参数、global改写导入别名等不能静默忽略，保持明确诊断。
