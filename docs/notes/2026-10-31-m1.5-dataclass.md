# 2026-10-31 M1.5 实现总结：@dataclass 降级与 .NET class/struct 双轨映射

> 目标：完成 Phase 1 里程碑 **M1.5 `@dataclass`**，支持 `@dataclass` 普通引用类型 class 与 `@dataclass(frozen=True)` 值类型 struct，打通构造调用、字段读写与跨函数传递。目标用例 `tests/e2e/phase1/m1_5_dataclass.py` 转正，`make check` 门禁全绿。

---

## 1. 设计意图与语义取舍

在 Python 科学计算与数值仿真场景（例如 N-Body 模拟、光线追踪、网格计算）中，三维向量（`Vec3`）、复数或质点对象会被创建上千万次。

- **CPython 的做法**：所有对象都是堆上的 `PyObject*`，必须经历内存分配与指针引用，且对象头与引用计数带来显著开销；
- **.NET 的优势**：.NET 具备第一类的值类型（`System.ValueType` / `struct`），支持在栈上分配、紧凑内存布局和零 GC 压力；
- **RyuPy 的设计决策（见 ADR-0008）**：
  - 普通 `@dataclass`：映射为 .NET 引用类型 `class`，继承 `[System.Runtime]System.Object`，支持属性读写；
  - `@dataclass(frozen=True)`：映射为 .NET 值类型 `struct`，继承 `[System.Runtime]System.ValueType`，标记顺序内存布局（`Sequential`），以纯值传递消除任何堆分配开销；
  - **语义差异防范**：在类型检查期严格禁止对 `frozen=True` 实例的属性修改（报 `E0203` 编译错误）；对于纯不可变数据，值拷贝与 Python 引用共享在外部行为上完全观测等价。

## 2. 编译链路全景

### 2.1 HIR 层（`ryupy-hir`）
- **修饰器识别**：在 `class.rs` 中解析类定义的 `decorator_list`，识别 `@dataclass` 与 `@dataclass(frozen=True)`，拦截非 dataclass 继承或非法参数；
- **类体解析**：提取 `name: type` 字段声明，拦截方法定义与默认值（Phase 1 范围）；
- **模块两遍扫描**：第一遍预先为顶层所有 `class` 与 `def` 分配 ID，建立全局符号表，支持类与函数间的前向引用；第二遍降级函数体与隐式 `main`，跳过 `ClassDef` 与 `from dataclasses import dataclass`；
- **语法降级**：
  - 属性访问 `obj.attr` 降级为 `ExprKind::Attribute { base, name }`；
  - 属性赋值 `obj.attr = val` 降级为 `AssignTarget::Attribute { base, name }`。

### 2.2 Ty 层（`ryupy-ty`）
- **模块解耦与行数治理**：将函数与内建调用检查拆分至独立的 `call.rs`，使 `check.rs` 减负至 530 行；
- **构造函数校验**：当被调用方为 `ExprKind::Class(cls_id)` 时，核对传入参数数量与类的字段数量（不匹配报 `E0204`），逐个字段比对参数类型，允许 `int -> float` 隐式数值提升，返回 `Ty::Class(cls_id)`；
- **属性读取校验**：检查基表达式类型是否为 `Ty::Class`，并在对应类的字段列表中查找，返回字段标注类型；
- **属性写入校验**：
  - 若目标类标记为 `frozen=True`，直接报告 `E0203: 不能修改被 @dataclass(frozen=True) 修饰的实例属性`；
  - 检查被赋值表达式与字段声明类型的相容性。

### 2.3 MIR 层（`ryupy-mir`）
- **结构化映射**：在 `build_program` 中遍历 HIR `classes`，构造 MIR `ClassDef`（记录字段名列表、`MirType` 与 `is_value_type`）；
- **模块解耦与行数治理**：将调用构建拆分为 `call_builder.rs`，使 `expr_builder.rs` 保持在 465 行；
- **语句与表达式构建**：
  - `ExprKind::Class` 发射 `Rvalue::NewObject { class, args }`（支持实参自动插入 `CastKind::I64ToF64`）；
  - `ExprKind::Attribute` 发射 `Rvalue::GetField { obj, field }`；
  - `AssignTarget::Attribute` 发射 `Statement::SetField { obj, field, value }`。

### 2.4 CIL Codegen 层（`ryupy-codegen-cil`）
- **类型定义生成**：
  - 为每个 dataclass 生成 `TypeDefinition`：普通 class 继承 `[System.Runtime]System.Object`，frozen dataclass 继承 `[System.Runtime]System.ValueType`（标记 `Sequential` 布局与 `sealed`）；
  - 为字段生成 `Field::instance(Accessibility::Public, ...)`；
  - 为每个类生成实例构造函数 `.ctor`（标记 `special_name` 与 `runtime_special_name`）：普通 class 内部先 `ldarg.0` 调用 `object..ctor()`，随后逐个字段 `ldarg.0; ldarg.i; stfld`；
- **指令栈化（`stackify.rs`）**：
  - `Rvalue::NewObject` → 发射 `Instruction::NewObject(ctor_idx.into())`；
  - `Rvalue::GetField` → 发射 `Instruction::LoadField { unaligned: None, volatile: false, param0: field_idx.into() }`；
  - `Statement::SetField` → 发射 `Instruction::StoreField { unaligned: None, volatile: false, param0: field_idx.into() }`；
  - 将指令翻译参数聚合为 `LowerCtx`，彻底避免参数列表超限（`-D clippy::too-many-arguments`）。
