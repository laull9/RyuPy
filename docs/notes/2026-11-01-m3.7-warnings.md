# M3.7 warnings 有限原生实现

## 项目需求与实现

冻结 wcwidth 0.2.13 在非法 UNICODE_VERSION 与低于最早支持版本的两个分支调用 warn；导入
一个空模块不能算支持。本轮实现 warn、simplefilter 与真正类型对象 catch_warnings，及
Warning/UserWarning/DeprecationWarning/PendingDeprecationWarning/RuntimeWarning/
SyntaxWarning/FutureWarning/ImportWarning/UnicodeWarning/BytesWarning/ResourceWarning 异常树。
异常参数保留原对象，包含一等构造与用户派生类；字符串化延迟到观察时。

- simplefilter 支持 default/error/ignore/always/module/once、类别继承、非负任意精度行号、
  append 优先级；修改过滤器会使旧抑制记录失效。
- 默认过滤保留主模块 DeprecationWarning，而导入模块中的同类警告与
  PendingDeprecationWarning/ImportWarning/ResourceWarning 默认忽略。
- catch_warnings 支持 record、action/category/lineno/append、嵌套、异常退出恢复、单次进入。
  record=False 不覆盖外层的捕获目标。记录具有 message/category/filename/lineno/line/source。
- 已有 Warning 实例决定类别并保留身份，error 抛同一实例。普通 message 用原始对象作去重键，
  不先 str；因此 record/ignore 不调用新建警告的 __str__，默认抑制使用 Python 哈希/相等规则。
  真正输出才格式化警告，且读取当前 sys.stderr，None 时不输出；非 IO 写入异常传播。

## 调用位置与真实修复

位置读取复用已有 Python 帧栈的冷接口 GetCallerLocation，不增加 TracePush 热 ABI。
ModuleForFile 只接受登记表中精确且唯一的文件标识；当前 driver 保存的标识仍可能是 basename，
两个包同名文件、未登记来源不能猜测模块，明确 NotImplementedError。栈级越界为 sys:1。

真实差分暴露旧 catch 恢复错误：handler 复用函数退出的 PopTo(depth)，把当前模块帧也弹掉，
随后 warn 被错误定位为 sys:1，进而隐藏本应可见的 DeprecationWarning。此次修正 handler 保留
当前帧，而正常函数退出仍弹帧；没有在 warnings 中假定 __main__ 来掩盖根因。

## 固定基线的 once 边界

采用 CPython 3.12.13 的真实 warn 行为，而非用文档概述代替实证：两个真实模块各发相同
warning，simplefilter('once') 捕获两条，同一模块重复则抑制。其 warn_explicit 的全局 once
行为不同，后者不在支持清单。目录差分 tests/cases/stdlib/warnings_once_modules 保存该边界。

## 明确暂缓

不支持 filterwarnings 正则、warn_explicit、-W/PYTHONWARNINGS 启动配置、替换 filters/
showwarning/formatwarning 钩子、catch_warnings 的非 None module、非空 skip_file_prefixes、
非 None source 的分配跟踪；这些未接入功能不可描述为完整 warnings。过滤器/帧栈是进程状态，
没有承诺多线程或 async 隔离。源码行仅在可读取文件时补充，不实现自定义 loader/linecache 协议。
WarningMessage 当前仅由捕获创建，不开放其构造 API。

## 验证与来源

- C# focused 覆盖原参数/身份、error、六种过滤动作、抑制失效、位置、嵌套、当前stderr、
  非 IO 错误、整数消息哈希相等及明确拒绝边界。
- 固定 CPython 3.12.13 差分：m3_7_warning_classes、m3_7_warnings、warnings_once_modules、
  自定义 warning 字符串输出与坏 __str__ 安全报告；均已通过并转正。初期3.12.14探针只作诊断，
  不代替固定版本验收。
- 依据公开API规范与黑盒行为独立实现，未复制 CPython warnings 源码：
  https://docs.python.org/3.12/library/warnings.html 。项目入口通过率另行记录，API通过不等于项目通过。
