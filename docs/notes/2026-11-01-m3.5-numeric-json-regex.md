# M3.5：数值、JSON 与受控正则

## 范围

以原 `m3_5_json_math.py` / `m3_5_regex.py` 为验收起点，补逐 API 错误与组合差分。
API 表见 ../stdlib-numeric.md，设计与边界见 ADR-0029。未用导入成功代替功能验收。

- math：常用标量、特殊浮点值、巨大整数对数与显式数值协议；time：墙钟/单调时钟/短休眠。
- JSON：保序大整数解析、hook、错误位置、循环检查与增量dump，写入回调按块执行。
- re：先解析限定 Python 子集再翻译，固定 Unicode 数据、码点索引、Python 捕获顺序与零宽推进。
- 原生模块异常经实际模块图识别，源码遮蔽/同名用户类不混淆；跨模块不能改写静态handler依赖的别名。

## 联调发现

- JSON ensure_ascii 必须转义 DEL；整数键和值共同遵循4300位转换界限。
- dump 不能整串编码后一次write，也不能一次绑定write；异常前缀和每块方法替换必须可见。
- repr 既有控制字符/Unicode行分隔符未转义会使正则和JSON差分失真，补不可打印类别与代理项转义。
- re的callable替换返回None代表空串，仍计入subn次数；不是TypeError。
- 正则解析器除模式长度外还需深度guard，不能让不可捕获的CLR栈溢出成为输入错误处理。
- IGNORECASE不能改变\w的分类成员；Unicode类别和字面量大小写扩展分开处理。
- 模块异常内部使用限定名，避免codegen用户类注册覆盖同名内建异常引用；生成器逻辑handler同步身份。

## 保留的边界

JSON自定义真值选项、bytes surrogatepass独立pending，未降低原验收。布尔选项仅bool/int/None；
默认深度256、整数转换4300位；cls定制拒绝。正文/代码均不称完整json域。
re未实现语法与类型明确拒绝；缓存/模式大小/递归深度/超时均有界，完整组元数据不伪装。
math宿主libm只对声明范围以容差验收，不承诺逐位跨平台一致。
既有模块后定义类与前方同名except-as绑定错误独立留 `m2_6_class_binding_order.py`，未冒充本轮修复。
