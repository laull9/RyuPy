# ADR-0038：严格内层浮点累加的跨迭代原生槽与出口物化

状态：严格内层规则通过真实差分与预设配对/JIT，接受有限默认；完整聚合门禁通过，不代表整个 M3.10。

## 来源与选择

ADR-0037 的短链已让矩阵三次乘法少 72 MB，但每轮最终 float 结果仍装盒。
当前实际 matmul MIR 有一个严格结构：pre 中 s=0.0，range header，
body 三次 GetItem 后 Mul / Add.inplace(s, product) / Use 写回 s，单 latch 与 exit。
更有影响的下一机会是跨 k 迭代保留 F64，只在出口 append(s) 前按需物化。
不新增 C# holder 或逐指令解释层，不改变矩阵源程序、规模或浮点加法次序。

旧 NumericAccumulator 在 entry 预头的简单循环仍先运行，连 float 初值也可能
走既有 holder；本切不为扩大命中重排整个流水线或改变 I64 路径。
真实目标是旧 matcher 未改写的内层循环。差分主例特意包一层 range(1)，
并用真实 MIR 强断言，不能拿未命中新方案的 entry 循环输出证明本优化。

## 最小结构与不可越过的边界

仅接受五个不同块：pre / header / body / latch / exit。
header 前驱恰为 pre、latch，body 仅 header，latch 仅 body，exit 仅 header；
header/body/latch/exit 不得是函数 entry。无 break、return、其它入口/出口。
pre 可以被外层循环重入，但每次都在原初值赋值之后重新初始化全部状态。

pre 中通过至多有限层、严格先定义的只读 Use 链追到 Box<F64>，不凭注解。
s 全函数静态写入只有 pre 初值与 body 最终回写；循环内唯一读取是已验证短链
最后一条 inplace Add/Sub 的左操作数。最终临时全函数唯一消费者必须是紧随的
Use 写 s；任何其它观察/别名/后继块或下一轮读取都拒绝。
header、latch 与 body 链外不得读取 s；无 EH、cell、环境或暂停。
容器读取仍在原位置逐次运行，绝不缓存长度、元素或重放用户 __getitem__。

复用原短链 matcher，不另造算术白名单。同一次固定源候选循环先尝试严格 loop，
成功就结束该候选，失败才走原短链；不再扫描新产生的动态慢路，不靠假 Line
或新增 MIR 持久标记阻止重复优化。最多 16 次总尝试、4 次 loop 成功，
预测扩张后的块/局部预算后才改写；预算失败不得留下半成品。

## 状态与提交顺序

状态仅为 F64 raw、bool mode、原 Dynamic s 缓存盒。
`mode && s == CLR null` 表示当前浮点结果尚未物化；None/其它对象不冒充脏标记。
pre 保原初值盒，精确类型真边初始化 raw；每次外层重入重新执行。

快路不再为 s 做快照/拆箱，而直接读取 raw；其它输入仍冻结并 exact-double 守卫。
按原顺序完成所有浮点步骤后，才 raw=result、s=CLR null；不每轮装结果盒。
慢路仅在脏标记为真时先物化旧 raw，再运行原整条动态链与原 Use 写回；
成功后保存原返回对象，重测 exact double，真边才重载 raw。用户协议抛错时
不得提前提交新 state。返回共享 float 的慢路结果保持原盒，而非立即重新装箱。
exit 也只对脏状态物化一次，再执行原出口语句；零轮保初值身份，
最后慢路返回的共享盒保持身份，之后再次实际算术才产生新结果盒。

## 先验验收与有限测量

pending 覆盖外层多次重入、零轮初值身份、getitem 次数/失败、首中末 custom、
__iadd__ 原对象、共享 float 最后返回与后续恢复快路、观察与多出口保原路。
独立结构测试必须证明最终临时唯一消费者、入口旁路拒绝、每次 reset 与慢路提交时机。
实际 CIL/JIT 要见内层快路无结果 Box，不能只按源码预估分配。

以已验证 short-chain 编译器为基线，预设一组两 tier、交错三进程×七样本，
资源和 JIT 独立；真实矩阵仍三次 100×100。不以原无优化基线重复计算前一切收益。
N-Body 若无命中则检查 CIL/hash/语义，不无意义重跑整组重负载。
至多一次有具体根因的修正，未达到收益门槛不默认启用；整里程碑再做完整门禁。
这不代表一般循环、容器布局特化或 SIMD 已完成。
