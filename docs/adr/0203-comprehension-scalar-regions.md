# ADR-0203：推导式有守卫标量执行区

状态：已接受；默认启用，完整门禁、原始26项和搬迁验收通过。

## 问题与表示

急切推导式的独立作用域保持不变。HIR显式登记合成来源，MIR复制该事实，
链接时保留；优化器不按函数名认定来源。生成器表达式及其恢复函数不使用急切来源标记。

在每个基本块内建立最多24条纯操作的定义使用DAG：整数Box/Use、加减乘、
常量非零除数的余数、富比较及真值。迭代、容器写入、用户调用和未知操作终止该区。
首次入口验证至多4个输入为精确Int64盒；先尝试全Int64范围证明，只有加减乘需要时
才使用[-(2^30-1),2^30-1]范围守卫。余数/比较通常只需类型守卫。
区间运算使用i128检查结果范围，无法证明安全的操作留在原路径；余数复用ModI64的Python符号语义。
范围只是快路准入，超过范围、BigInteger、bool、浮点、外来对象及用户协议正常执行原语句。

区内保留原生I64/Bool，出口按原定义顺序物化。已有盒和别名沿原引用传播；
新鲜结果的多个别名反向要求同一个定义物化，禁止各自装箱。
命名绑定及所有区外读取均视为活值；短命算术/比较中间值不创建Python对象。
守卫失败发生于任何区内效果之前，直接进入原区且只执行一次；快速区没有用户协议、
容器写入或可抛出的算术。源码行号在两路保持原顺序。

## 收集器及边界

list/set共享私有收集器证明：显式来源、精确空容器初始化、单一定义、无cell/free逃逸，
并验证方法名与单位置参数。分别直调ListAppend/SetAdd；集合插入仍保留hash/eq及异常时序。
用户普通容器的方法查找不受影响。带表达式来源审计的构建入口继续沿原集合/容量构造路径。

每函数最多12个候选，入口预算256局部/64块。env/cell、模块状态、EH、source handler、
direct globals和trace V1保留原路径。分析完成才改写，新增慢路不再次匹配。
本切同时消除精确enumerate立即二元解包的临时tuple与object[]。MIR核对当前值→隐藏临时→
UnpackSequence(2)→索引0/1的完整使用链，且这些容器临时在全函数没有额外读取；
两个输出分别由守卫后的固定ABI取得。索引盒先构造、底层Current恰读一次；目标写入仍在后续原CFG。
未知迭代器走原IterValue/UnpackSequence，保存整个tuple或cell捕获不进入此快路。
无过滤单层list推导式另用私有构造器；只为精确PyRangeIter读取剩余项数，Int128计算，
最多预留65536个引用槽。不推进游标、不调用length_hint；过滤/嵌套循环和未知游标保留空容量。
预留不预填元素，append及其错误时序保持。初次分配时点变化与容量上限列入本ADR资源取舍。
range输入取消装箱与其它批量构造器仍待实施。

资源耗尽和短命临时析构时点沿既有GC/refcount合同；新鲜中间盒减少会改变分配时点。
常用结果、对象身份、别名、协议顺序和错误必须同次CPython验证。
