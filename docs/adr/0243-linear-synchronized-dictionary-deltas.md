# ADR-0243：同步字典的线性快照比较

- 日期：2026-11-19。
- 状态：定向行为及性能验收通过；完整应用仍有独立阻塞。

## 背景

启用 `synchronized` 的 provider 会在调用、回调和异常边界同步真实 CPython 字典及其托管
别名。旧实现枚举快照后，又用嵌套 `Any` 确认存活键、写回值和插入顺序；即使没有修改，
也反复走二次扫描。ExplorerPro 第一次显示经过原应用翻译过滤器，跨域访问放大了此成本。
直接运行原翻译模块与目录，不依赖 Qt，也能复现。

## 决定

先逐项比较有序键、值的引用，完全一致不建立索引、不写回。变化时只对实际键引用建临时
位置索引；存活的旧键必须占据新序列前缀且顺序不变，才能增量删除、更新和追加，否则走
原整表重排。临时索引不调用 Python `__hash__`／`__eq__`；实际写回仍使用既有协议。

保留值覆盖检测、原 key 身份、嵌套别名、异常前副作用、生命周期登记、GIL 与所有权边界。
不使用 `PyDict.Version` 跳过值读取（该版本只表示结构变化），也不靠特定 CPython 私有
字典字段或版本钩子。跨域调用仍需观察真实 CPython 字典，线性扫描、转译和分配都未归零。
普通 Runtime 字典、proxy 模式和同步列表不变。

## 验收

`tests/cases/stock_module_namespaces/synchronized_maps/` 使用 1100 项整数键字典和
元组/文本键的共享子容器，覆盖不变、覆盖、删除重插、别名、异常及原键身份。
CPython 3.12.13／3.13.3 的 JIT、目录 NativeAOT 共四个产品通过删除输入搬迁；
另外 3.12.13 的捕获 builtins 与导入回调两个既有场景各通过两种形态。CPython.Tests
固定 CPython 3.12.13 的 45 项全部通过。同一外部调用内重排后抛异常的回归使用现有
`container_transfer.py`，同版 JIT 与目录 NativeAOT 删除输入搬迁通过。
完整 `make check` 通过：3484 项 Runtime、353 项 driver 单测及 514 项编译端到端通过。

macOS arm64、固定 CPython 3.12.13、同一 .NET 11 SDK：原 1185 项翻译目录 prewarm 后
断言一致，每轮 15 次非命中查询，四轮平衡顺序。JIT 稳态中位数从 `938f9107` 的
2.945 秒降到 0.145 秒（约 95%）；整进程从 4.358 秒降到 1.023 秒。CPython 相应为
约 15.75 微秒与 22.55 毫秒，差距仍显著。仓外样本
`~/.cache/ryupy/validation/stock-dict-bridge/20261119T081712-translation.json`。
该局部测量不代表应用已通过，完整 Cocoa 显示及业务回归另验。
