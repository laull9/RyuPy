# ADR-0002：MIR 采用非 SSA 的「局部变量 + 基本块」形式

- 状态：已接受
- 日期：2026-10-31

## 背景

roadmap 中 MIR 被描述为「基于 CFG 基本块的 SSA」。需要决定 Phase 1 的 MIR 具体形态。

## 方案

### A. 严格 SSA（每个值只赋值一次，汇合点用 φ 节点）
优点：数据流分析（常量传播、类型收窄、逃逸分析）写起来最简洁。
缺点：构建需要支配边界计算或 Braun 等人的在线算法；输出 CIL 前必须做 φ 消解（插入拷贝），对初学者是两块额外的硬骨头。

### B. rustc 风格：可变局部变量 + 基本块 + terminator（非 SSA）
优点：HIR → MIR 直接翻译即可；CIL 本身就是「局部变量槽 + 求值栈」，几乎一一对应；调试时 MIR 与源码变量对得上。
缺点：做数据流优化时需要经典的迭代数据流框架（gen/kill），或临时构建 SSA。

## 决定

Phase 1 选 B。Phase 3 引入流敏感类型收窄、逃逸分析时，再决定是在 B 上做迭代数据流分析，
还是在 MIR 之上构建一个只读的 SSA 视图（不改变 MIR 本身的存储形式）。

## 后果

- 先拿到端到端可运行的编译器，SSA 作为后续独立的学习主题。
- `petgraph` 推迟到 Phase 3 再引入（届时用于支配树计算）。
