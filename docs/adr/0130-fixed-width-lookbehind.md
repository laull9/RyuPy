# ADR0130：无内部捕获的固定码点宽度后顾

- 日期：2026-11-06。
- 状态：有限功能接受；复杂协议与成本开放。

## 决定

在同一parser token路径内，仅进入后顾时建立冷宽度摘要。连接加法、分支取范围、重复
乘法均按Python码点/字节，不按UTF16长度。全模式受支持语法解析后按源码序验证定宽，
用真实re.error及None位置属性报告变宽。原Unicode原子与边界检查原样保留。

只准入无捕获、无引用/条件/嵌套断言/显式anchor或boundary的纯字符正文，外围旧语法保留。
直接使用.NET后顾会反向消费，捕获等可观察状态不能轻率迁移。超过宿主计数/累计宽度
边界明确NI，D009相邻独立代理差异及全部完整长尾正例继续pending。

未知字母escape的定位/局部现场，以及有限min>max量词的token期检查一并修正，避免新
宽度检查改变支持域内语法错误优先级。不扩整个Compile catch，也不承诺全部旧错误。
