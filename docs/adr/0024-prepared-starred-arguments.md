# ADR-0024：暂停调用的位置星号准备

状态：已接受。

## 背景

旧StarArg只保存源，最终FlattenArgs才迭代；若多位置实参之间暂停，源可能已变更，或迭代
副作用/错误发生太晚。但固定CPython3.12中唯一位置项为`*source`时确实延至关键字准备后才迭代，
不能无条件改成每个star立即物化。位置参数组先于关键字组，不按两组交错的源码文本顺序。

## 决定

PreparedCall有star时使用专用数组准备模式：多个位置项的star通过既有MakeList/ListExtend
立即得到私有快照，再封装StarArg；唯一star位置源保持原延迟策略。普通无暂停路径不变。
复用CallValue/DynBuiltin和既有内建签名门禁、方法提前绑定，不新增通用参数builder或运行时ABI。
`**`映射快照、批次重复键时序及通用mapping仍独立未支持；不把本切称完整调用兼容。

## 后果

混合star多一个私有列表及最终复制，换取正确性；全局部spill可能保留该快照到结束，无性能加速宣称。
后续可让运行时直接消费已准备数组以减少复制，但必须用性能测量支持；不得重新延迟原源迭代。
差分覆盖源修改、多个生成器源副作用、非法源报错早晚、语法关键字在star前、方法绑定和内建print。
