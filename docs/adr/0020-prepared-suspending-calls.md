# ADR-0020：暂停调用先固定目标，保留普通调用热路径

- 状态：已接受
- 日期：2026-11-01

## 背景

把方法查找留到实参求完之后，在yield参数下会观察到暂停期间替换的新方法，也会延迟property
副作用和缺属性错误。类似地，保存Global操作数而不立刻读取会把模块函数/类目标推迟到恢复后。
普通调用现有PIC避免绑定包装分配，不应为新增暂停路径无差别改慢所有调用。

## 决定

HIR为无*/**且实参会暂停的调用生成PreparedCall。MIR先求callee：普通方法立即通过PrepareMethod
取属性，其他目标强制保存到Dynamic临时，再逐个求参数并调用。不可调用性检查仍在参数求完后，
不能因为提前读取属性而提前抛TypeError。lambda默认值属于当前求值作用域，其内部yield同样触发准备。

普通对象使用GetAttr；内建对象绑定接收者、经存在性检查的名字、类型专属静态入口，恢复时不再
Python属性查找。内建存在性表必须与实现分派同步，专测覆盖全支持集和缺失项。prepared入口在
参数全部求完后校验支持的arity，再执行副作用，避免旧便利分派忽略多参或抛CLR越界。

暂停调用承担一次目标临时和必要绑定包装的成本，普通无暂停CallMethod/PIC不增加分配。
没有性能倍率承诺；未来可用可证明安全的预绑定缓存优化，但不能重新延迟可观察方法查找。

## 边界

星号实参的立即展开与重复关键字错误时机另做竖切。直接dataclass暂停构造仍报E0305，不能把专用
字段构造错误替换成普通PyClass。旧内建构造ABI未覆盖完整签名的入口，暂停调用暂只开放单位置
参数并在HIR报告其他形态；异常构造参数数组缺口沿用ADR-0018记录，不静默丢弃后续yield。
