# ADR-0182：源码仓库与即时 CPython 比较

- 状态：已接受规则；历史清理由现有子代理执行，测试驱动迁移待实施
- 日期：2026-11-13
- 决策来源：用户要求简化项目，Git 仅保留必要代码、输入与文档
- 更新：ADR-0181 及结构规划中的 golden、快照、历史比较产物保留规则

## 决定

Git 保存产品源码、测试驱动与断言源码、必要的手写输入和包资源、构建配置、依赖锁定信息、
许可证及人工整理文档。所有测试输出、构建产物、比较结果、生成 golden、`.snap`、性能原始
样本和机器生成报告都禁止提交；改名为 fixture 或嵌入文档的大段输出仍按产物处理。
项目中禁止遗留 `.patch`、`.diff` 等文件。必要修改落实到正式源码，差异由 Git 本身表达。
手写测试程序中的结果断言允许保留，禁止把生成快照机械搬进源码伪装为断言。

Python 语义比较每次先运行固定版本 CPython，立即取得预期，再执行 RyuPy 并比较。
不读取历史 stdout/golden，不在 CPython 缺失、超时或异常退出时回退到旧预期。
CPython 失败时该次比较失败或标记环境阻塞；预期异常用例按源码声明的异常合同判定。

CPython 和 RyuPy 使用相同源程序、版本锁、参数、stdin、locale、时区和必要环境设置，
但各有全新独立工作目录及数据库，避免基线运行先改变被测输入。HTTP fixture 每臂重置。
冻结可控随机种子和时钟输入；临时路径、端口等不可固定字段只按显式字段规则归一化，
不得过滤业务值、异常类型、退出码或副作用。数据库与资源结果由独立源码断言验证。

CPython 无法生成 HIR、MIR、CIL 或 RyuPy 诊断预期：这些测试改用结构、不变量、错误码、
位置及必要消息的源码断言。IR 文本只用于临时调试，不维护磁盘快照验收链。
性能样本当次配对生成，文档只保留人工总结的结论、环境与重跑命令。

## 临时目录与提交门

每次测试创建仓库外临时工作区，退出时清理；失败调试仅按显式选项保留在仓库外并打印位置。
构建缓存允许放在已忽略的 `target/`、`bin/`、`obj/` 等工具目录，禁止成为测试归档区。
补丁、差异报告与测试结果不留在项目目录，即使路径已忽略也不作为长期存储。

忽略规则防误加，后续提交/CI 检查同时审核已跟踪文件，拦截强制添加的禁入产物。
准入按文件用途判定，不能仅靠扩展名：必要 `.json` 配置可保留，结果 JSON 必须删除。
必要输入须能说明用途和来源；可由测试代码生成的数据库、压缩包与二进制样本改为运行时生成。

## 清理与迁移

1. 全历史及所有分支清理后强推；已有清理备份沿用，按用户最新要求直接同步主工作区并推送，不再新增备份流程。
2. 保留必要实现；遗留 patch 中独有代码先落实到源码，备份承担恢复功能。
3. 删除旧产物后列出失效消费者，测试驱动按套件迁移到即时比较或结构断言；不建兼容层。
4. 保留用例 ID、输入程序和 pending 状态；不能删除用例、跳过失败或降低断言来使检查通过。
5. 历史文档可保留人工结论，注明原始产物已清理；不为恢复旧链接重新提交产物。

本轮主代理整理规则和路线，不实施测试框架改造。清理完成与测试驱动迁移分别报告，
驱动仍引用旧产物时明确列为阻断，待迁移后重新跑验证。
