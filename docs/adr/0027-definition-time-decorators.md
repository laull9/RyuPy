# ADR-0027：定义位置装饰器与混合 dataclass 表示

状态：已接受。完整 M3.3 聚合门禁与只读复审通过，按整里程碑提交。

## 背景

装饰器可以返回任意对象。若调用继续按原 FuncId/ClassId 静态直达，会绕过公开绑定；
默认值或装饰器抛异常也不能提前覆盖旧定义。静态 dataclass 的 CLR 实例没有动态类链接，
直接把其构造包装为普通 callable 会使动态字段、身份与方法查找失效。

## 决定

HIR 保留源码顺序的装饰器表达式与独立公开模块绑定。MIR 在定义位置先求值并冻结所有
装饰器，再求默认值、创建原始函数及其元数据，逆序应用，全部成功后才写公开绑定。
嵌套函数保留已有共享 cell 环境。模块导出优先公开模块槽，不能再次导出私有原始函数/类。
类体读取此前同类名字使用原始命名空间，不触发 descriptor 绑定或基类查找；方法体不捕获类作用域。

普通函数保存可变 __name__、__doc__、__annotations__ 与用户属性字典；包装器不自动复制
原函数信息，functools.wraps 在 M3.6。注解范围仍是现有可识别的基础类型、用户类和 None，
不因提供字典而宣称支持任意注解表达式、延期注解、__qualname__ 或完整反射。
无文档/标注的函数不发元数据调用，属性/标注字典按首次读取惰性分配。
一等内建函数按名字缓存身份，调用复用既有内建参数分派，而非用 None 代替未知函数值。

纯 @dataclass 保留已有静态 CLR 字段/构造优化。与普通装饰器混合的 dataclass 走
PyClass/PyInstance，相关标注与 self 保守 Dynamic。原类先记录字段声明，逆序执行到
Dataclass 标记时才对当前输入类的声明激活 init/repr/eq/hash/frozen；不能把原类字段
强套到下层装饰器返回的替代类。frozen 选项属于当前装饰器标记，不属于替代类。
不使用逐实例反射或 Reflection.Emit。property getter/setter/deleter 复制式更新描述符；
classmethod 从实例或子类访问均绑定实际访问类，定义类上下文另行保留。

## 代价与边界

装饰器与默认值保存增加定义期临时槽；装饰函数每次定义分配函数对象/默认值数组。
混合 dataclass 放弃静态字段直达，换取正确动态身份与替换语义；纯 dataclass 不付此代价。
未测量加速收益，不宣称此实现更快。后续只能在证明公开绑定不变时做守卫优化。

专用 dataclass 标记只识别真实导入（含别名），仅支持无参数或 frozen=bool 字面量；
导入别名若有函数global写入则明确拒绝专用标记，避免把动态重绑定静默冻结。
重复标记、默认字段/default_factory、复杂继承和自定义 dataclass 方法保持明确诊断。
property安装到字段后支持显式传参初始化，省略实参时property作为默认值的语义尚未支持；
普通字段默认值在激活前明确拒绝，动态dataclass继承亦明确拒绝。
完整 __dataclass_fields__/__dataclass_params__ 标准库对象留给 M3.6，不伪造占位。
函数内 class、多重继承、元类和任意自定义 descriptor 仍不在本里程碑范围。
动态基类若被装饰替换为异常类但没有对应 CLR 工厂，明确 TypeError，不构造伪异常对象。

## 验证

pending 差分覆盖装饰表达式/默认值/类体的顺序、逆序应用、失败保留旧绑定、闭包包装、
可调用对象、方法与 property、混合 dataclass、替代类/frozen、同名类身份、跨模块公开导出，
并以固定 CPython 3.12.13 比较。运行时专测覆盖元数据变更、描述符与绑定错误。
完整make runtime/make check通过：177 C#单测、88编译e2e/18 ignored、102 CPython基线。
固定项目仍原生0/20；attrs首阻断前移至Protocol基类，不计通过。
