# ADR0188：离线校验已交付的AOT目录

状态：实现与真实应用验收中，未合dev/main。

## 缺口与选择

既有发布事务会核对候选dist，但用户复制、解压或搬迁后没有公开命令复验交付目录。本切只公开既有只读核验能力：`ryupy verify <dist>`。不新增分发配置、ABI/provider、构建缓存、压缩格式或另一个清单解析器，也不重新运行编译。

driver复用`aot_layout_files::verify_manifest`，CLI只解析参数和输出JSON。支持既有AOT清单版本号1–8，核文件相对路径、普通文件/目录、清单列举的完整文件集合、size/SHA256以及恰一个native_executable角色。预算保持既有32MiB JSON、8GiB单文件、64GiB整树、100000条、64层。失败非零退出，不修复/删除/写入交付树，不调用dotnet/Python/ILC。

## 准确承诺

通过只表示清单与当前读到的文件自洽。攻击者同时改文件和清单可以重新形成自洽集合，因此这不是来源真实性、签名或防恶意篡改认证。它不解析/认证完整schema语义、二进制格式、原生依赖闭包、执行权限、目标机兼容性或可运行性。JSON显式将authenticity、runtime_compatibility、schema_semantics记为not_checked；RID仅作为reported_target_rid回显，不据此认定本机可运行。

既有文件全集合同允许额外空目录，不偷偷扩大成目录全集合同。根本身及其内部链接/reparse拒绝，但不声称所有祖先都是非链接；不先canonicalize掩盖根链接。只读核验不是原子快照，也不保证抵御并发敌手替换。不会返回分次重读的manifest摘要来冒充与初次解析绑定的签名。

验包不接受编译全局开关，前置/后置的metadata、实例策略、trace及实验参数均拒绝，避免看似应用配置却静默忽略。输出不含机器绝对源路径、时间戳或构建动作；相同内容搬迁后摘要不变。

## 验收

1. driver小夹具覆盖受支持版本、文件全集、缺失/多余/损坏、重复/自引用/路径逃逸、native角色数量、未知版本、JIT清单、链接以及不写树。
2. CLI验证参数与冲突，不把全局配置交给来源解析。
3. 固定真实pyfiglet的metadata入口和553字体，以及binaryornot应用：公开build、原位验包、搬迁隐藏源/build后验包，再独立执行Native与固定CP原流比较。验包进程用空PATH和失效工具哨兵，记录无工具启动与树前后字节/权限不变。
4. 三平台真实SDK构建及搬迁门，保留全部失败。成功验包与成功运行分别记录，不用其一代替另一项。

这项交付体验改进不构成性能提速证据；旧直接入口性能A/B仍属于原提交，不外推到新catalog/ABI或验包成本。
