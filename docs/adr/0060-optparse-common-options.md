# ADR-0060：optparse 常用选项解析的有限实现

状态：本地有限实现及完整门禁通过，尚未发布。

## 动机与路线

2026-11-03 在未发布候选08c5的锁定pyfiglet1.0.2固定入口单次验证中，CP参考及编译
成功，JIT首败缺少optparse。原始输入、官方源码、产物与双流已独立核验；仍未进入
字体读取，不增加历史5/20项目计数，也不是公开main的执行结果。

pyfiglet只在模块顶层导入OptionParser，真正解析调用位于另一个CLI入口。不能为跨过
导入提供空模块或假类。因此选择通用的有限OptionParser、Option、Values和真实异常树。
直接编译固定CP标准库源会牵入额外依赖，optparse自身还有当前不支持的exec等静态门槛；
这只是源码分析，没有把未运行路径算作新失败或成功。

## 阶段边界

A先实现真实对象、选项声明与默认值；B实现参数解析与错误退出；C实现默认帮助布局。
B/C未完成时不登记对外模块，不把开发阶段的显式拒绝当最终实现。现有argparse不变，
两套协议不能直接别名：optparse返回Values和剩余参数，交错规则、取值与默认转换时点
均不同。

六类错误使用真实CLR继承及静态catch身份，构造绑定与原位置args分开。业务字段保原
引用与实际格式化时点，终端显示模块限定名。首切不开放这些自定义初始化异常的用户
派生，不以缺失构造器生成无效CLR类；合法派生正例另保pending。

## 有限支持目标

支持常用单值store、store_true/store_false、string/int/choice类型、短选项簇、长选项
缩写与等号、--、交错参数、默认值和重复解析。明确保Option元数据与parser.defaults的
区别，显式Values身份，以及调用者参数列表不被修改。默认字符串转换先于处理选项；
参数解析的错误退出保真实异常上下文，不能广泛吞掉用户转换或输出错误。

默认帮助采用实际COLUMNS快照、码点宽度和原双流比较，不以归一化文本掩盖差异。
公开自定义formatter、OptionGroup、callback、复杂nargs/动作、完整类继承和内部状态
猴补不是本切目标。合法未支持能力明确拒绝并保CP正期望，不宣称完整optparse或pyfiglet
CLI兼容。非ASCII dest没有显式metavar时，帮助生成暂明确拒绝，避免用CLR大写近似
冒充Python完整Unicode映射；普通解析不因此被禁止。
