# ADR-0193：模块静态槽的有限字符串累加

- 状态：已接受，有限准入范围接入默认流水线
- 日期：2026-11-15
- 关联：ADR-0033/0034、ADR-0182

## 背景

原始str_concat/containers顶层字符串循环存在巨额累计分配。既有holder支持精确字符串延迟物化，但旧matcher只覆盖entry的有限局部+=，不能直接放宽签名门禁解决模块槽位。

## 决定

独立StringAccumulator匹配模块静态槽：预头精确字符串字面量初值、常量后缀、严格自然循环拓扑、全循环指令白名单和单次临时定义/使用。静态StrConcat与动态LoadName/Box/Add两条真实管线均验证；实例模块/EH/环境及字典反射合同拒绝。

创建内部holder并在原循环顺序追加；原计数器发布及已绑定检查保留。出口物化并按原Str或Dynamic槽类型写回，现有别名不变；零次循环保留初始引用，不增加未绑定读取。

## 边界和验收

字符串Box在CIL为no-op，几何增长仍有分配。按项目低影响差异规则，接受分配策略、资源耗尽时刻和资源错误期间部分模块绑定的差异；外层捕获资源错误时，目标槽位可能仍为初值。checked容量溢出沿现有CLR异常路径，长度/容量受Int32及CLR实际对象限制。这个取舍仅覆盖资源耗尽；普通可达回调、身份、别名和异常顺序保持原合同。

主代理真实源管线14测与严格Clippy通过；JIT/NativeAOT及输入隐藏后的搬迁差分通过，完整26项AOT与最终6项重点复测通过。完整make check退出0，编译e2e469项通过/284忽略。异构复审未发现阻断，主代理采纳上述有限资源边界并晋升默认实现；数据见字符串专项文档。

主代理进一步收窄为编译器产生的+1 range条件/回边模板，拒绝普通while、非单位及负步长；环体禁止修改原生控制局部，以避免普通步进溢出时的延迟写回。原始两项基准仍命中，非单位range与while拒绝测试通过。

每次Pass处理一个候选循环；同函数其余循环及跨preheader初值沿原路径执行，后续按实际热点扩展。
