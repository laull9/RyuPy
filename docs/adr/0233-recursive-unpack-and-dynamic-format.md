# ADR-0233：递归解包与动态格式规格

- 日期：2026-11-17。
- 状态：已完成定向差分和九产品搬迁，完整集成检查继续运行。

## 决定

为通用Python语义新增递归 `SequenceTarget::Sequence`。每层先准备本层值，再从左到右
执行目标；轮到子序列才开始内层解包。外层先完成的写入保留，内层失败不回滚；尚未到达
的目标不求值。星号规则按层独立检查，叶目标继续使用名字、属性和下标的原通用实现。
普通平坦字面量保留原长度/下标快路，内层未知对象复用既有UnpackSequence/UnpackEx。

保护区内序列写入只记录已有的确定赋值事实，不能把成功路径的新绑定带到异常路径。
槽位仍保留实际部分写入，后继读取用既有LoadChecked区分已写值和未绑定。递归局部绑定
同时进入类型分析、赋值标记和推导式私有收集器的写入检查。

f-string规格使用显式静态/动态两种HIR形态。静态规格继续发射原常量，动态规格递归构造
字符串。求值顺序为主体值、规格表达式、转换、格式化；暂停和异常沿既有MIR控制流处理。
普通Python实例的__format__复用已验类型级格式协议，精确内建数值保持原格式快路，
非法规格的消息补齐接收类型。

两种能力均只依赖语言结构，无第三方库名分支。
