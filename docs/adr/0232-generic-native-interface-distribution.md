# ADR-0232：通用原生接口与共享分发归属

- 日期：2026-11-17。
- 状态：实施中，按下述独立完成门记录结果。
- 接续：[ADR-0173](0173-declarative-cabi-signatures.md)、[ADR-0231](0231-optional-import-dependency-closure.md)。

## 目标与决定

第三方兼容与分发以协议、声明和文件事实驱动，非标准库禁止按某一个第三方库名选择
专用实现。允许为性能结合 `.pyi`、头文件、实际导出符号与探针自动推导
ABI、布局、所有权和生成调用适配，保留推导依据、适用条件及跨场景实测。

安装闭包的一个部署目标可以归多个发行所有。相同规范目标与相同真实源文件只部署一次，
保留全部owner、metadata与许可证。不同真实源冲突、同发行重复RECORD、缺失与越界
继续给出精确诊断；既有安全环境内符号链接按原规则物化，避免收紧合法安装布局。
这套合同适用于源码、类型声明、普通数据与原生文件，判断无需后缀白名单。

从实际分发闭包导出接口目录，区分CIL来源、Python源码、类型声明、CPython扩展与附属
共享库。静态读取二进制导出表核验扩展初始化入口，避免把普通同后缀共享库登记为扩展。
构建期不加载应用扩展。`.pyi`保存函数、参数、注解与来源信息，作为推导和调用计划的
输入；导出的机器ABI结论同时保存已取得与尚未取得的证据。

已验证的固定C ABI绑定同时发布可供类型工具读取的`.pyi`与`.abi.json`，位置在
`_internal/interfaces/v1`，由artifact manifest精确关联。stub保留真实位置专用调用形状，
机器合同保留符号别名、RID、整数范围、bool8、浮点舍入与buffer的`borrowed_call`规则。
类型注解表达不了的约束继续由真实绑定器检查；机器范围和生命周期检查继续保留。

外部原生依赖通过`--cpython-native-components`的schema 1声明加入冻结payload。
名称、版本、来源、构建功能、许可证和旧加载名属于部署数据；实际映像的架构、
LC_ID_DYLIB、current/compatibility版本和加载边由同一通用审计器核验。
当前声明接入的是macOS arm64 Mach-O合同；ELF/PE附加组件另行接入并验收。

部署可显式声明目录scope、其完整members集合及selected子集。全集变化立即使声明
失效；每个保留和排除目标及其原生加载边进入报告。未声明目录保持完整收集，所有
选中映像继续严格闭包验证，排除必需依赖导致构建失败。此机制服务于产品部署范围，
编译器中禁止出现第三方名称、插件名称或产品名称的选择分支。

## 分层

driver负责接口发现、导出、依赖与部署计划；syntax独占Ruff解析器并提供显式版本和
stub入口；HIR/MIR决定业务语义；codegen发射静态CIL与显式机器调用；Runtime/provider
承担对象、回调、句柄与引用管理。NativeAOT调用目标在构建期固定。

## 完成门

先重现旧版共享文件冲突，再验证至少两组不同命名和布局的安装组合，其中包含原生
扩展、资源与接口声明；冲突、缺失、符号链接及重复记录负例保留。实际JIT/NativeAOT/
OneFile产品删除输入和构建环境后搬迁执行，metadata、资源与原生功能均参与差分。
原大型项目构建到达的下一阻塞单独报告，真实GUI/服务与完整业务闭包逐项验收。
