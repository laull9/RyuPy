# ADR-0022：增量赋值冻结目标与索引

状态：已接受。

## 背景

旧降级只缓存复杂子表达式，认为名字可重复读取。但 `a[i] += f()` 中的 f 可以重绑定
全局或闭包 a/i；yield 也允许外部在恢复前修改绑定。读取与写回不能因此选择不同位置。

## 决定

HIR `aug_assign` 除不可变字面量外一律将基对象与下标先写入隐藏局部。切片整体只构造一次。
之后按读取旧值、求RHS、原地运算、写回顺序执行，沿用现有生成器全局部堆帧保存目标。
这修复普通同步路径，也解除属性/下标增量赋值跨暂停的保护诊断；不改变普通变量赋值规则。

## 后果

增加局部复制、既有if True包裹分支和生成器spill槽位，但不引入额外函数/环境或每元素对象分配。没有测量加速收益，
未来可用别名/副作用分析证明安全后消除复制，不能凭名字形式猜测稳定性。
原地运算成功而最终写回失败时保留已发生副作用，不回滚。property setter既有未支持状态不变。
差分覆盖模块/闭包重绑定、目标各部分暂停、切片身份/求值次数、读取失败先于RHS以及写回失败。
