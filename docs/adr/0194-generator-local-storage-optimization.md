# ADR-0194：生成器临时槽活跃性候选

- 状态：测试候选；产品入口关闭，未做性能验收
- 日期：2026-11-15
- 关联：ADR-0141、ADR-0182

## 背景

优化前 generators 基准显著落后。每个实例只创建一次 frame，恢复时复用；并非每次 yield 分配数组。PC 经 PyInt.Box，小整数状态可以命中缓存，撤回逐次分配 24 字节及 91.55 MiB 的推算。真实分配贡献仍需剖析。

## 候选决定

复用 MIR 完整操作数读取器，按 CFG 后向计算跨挂起活跃集合，预算耗尽返回 None 保留原保存。仅分析非 product、无 EH 的生成器。

所有参数、用户命名槽、cell 和非 Dynamic 槽保留。仅对不跨恢复点活跃的未命名 Dynamic 编译器临时，在暂停时写 null；恢复端对这些动态槽不执行静态拆箱。保留所有静态槽，避免全量恢复时读 null 引发错误。

保留命名槽旨在保护 locals/闭包等可观察状态，整个观察合同仍需端到端验证。send 接收局部在恢复边重新定义，算法保守保留必须保活项。EH/product 回退原路径，finally/throw 路由未改写。

## 显式选择与验证状态

主代理删除了编译期环境变量开关。当前仅通过测试专用 lower_with_liveness_for_test 显式运行候选，产品 lower/lower_with_trace 保持原全量保存。

主代理执行过 5 项活跃性与实际降级结构测试，验证预算拒绝、复杂读取、合流、保活集合及 null 写入/静态保存，实际降级后的 MIR 验证通过。此前全 MIR 单测为344通过、4忽略。新增预算断言后需继续复验。

端到端、AOT、搬迁和 A/B 尚未执行，pending 用例保留。候选清理 Dynamic 临时仍保留 ArraySet/null 写入及全量恢复，吞吐收益未知，未晋升默认。后续显式产品实验需通过 Session/编译选项及产物记录接线，不能恢复隐藏环境开关。
