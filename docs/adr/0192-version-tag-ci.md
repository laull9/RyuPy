# ADR-0192：日常单平台与main版本tag三平台验收

- 日期：2026-11-14
- 状态：已实现，按用户指定的`v*`命名触发。

## 决定

35份工作流收敛为5份：一个日常Linux门、一个版本tag入口和三个可复用发布套件。
日常dev/main推送及PR只运行单个Linux作业；三平台和Python七版本矩阵仅在main上的版本tag运行。
GitHub的分支和tag过滤分别匹配ref，不能仅把main与v*写进同一push配置表达交集，因此使用
独立入口校验：真实tag推送、检出提交相同、提交为origin/main祖先，全部满足后才调用矩阵。

入口采用只读contents权限，不允许workflow_dispatch绕过；套件只暴露workflow_call。
未合并分支tag在入口失败，矩阵保持未启动。祖先版本允许补发，注解tag解析到实际commit。
日常按来源仓库与来源分支共享并发槽位，push和PR互相去重；fork按仓库隔离。
新提交取消同一分支的旧检查，版本验收保持各tag独立，不自动发布Release。

31份专项实验工作流归档到Actions发现目录之外，原YAML正文保留；历史读取器切换至归档目录。
产品测试驱动、本地make check和已验收的三套发布步骤保持可执行。

## 验收

真实临时Git图覆盖main当前tag、main祖先注解tag、未合并dev拒绝、分支/非v tag/手动事件拒绝、
错误检出拒绝。工作流还校验触发器、main-tag依赖与本地复用路径，归档正文与迁移前逐字节相同。
YAML/表达式以actionlint检查，日常门的实际运行单独登记。版本矩阵在本次收敛前已21/21通过。
