## 实际路径与范围

最小源码的顶层字符串推断为静态StrConcat；完整str_concat/containers源码在动态模式下使用LoadName、字符串常量Box、DynBinary(Add)、SetGlobal。两条路径均要求相同的精确字符串和无观察循环证明，不能用最小正例代替原始基准命中。

匹配严格5块自然循环，前驱可不是entry。目标在preheader最后一次赋值必须来自直接字符串常量，或唯一确定的Box(Str常量)临时；初值引用在原点已确定，后续只允许原生计数初始化及确切Box(I64常量)/Unbox(I64)链。零次循环不提前读取未绑定名。

整个header/body/latch采用白名单：无用户调用、动态协议、属性写入、别名观察。除累加切片，仅保留原生计数器/布尔计算、精确整数计数器装箱和发布，已证明为true的绑定检查。模块实例环境、EH、cell环境、globals/locals观察合同拒绝。

通过已有NumericAccumulator holder追加，仅在出口物化并按原静态Str或Dynamic槽类型写回。字符串Box本身不是分配，StringBuilder仍会几何扩容和分配chunk。新模块不新增运行时ABI。
